## Deploy instructions
- update .env to live links at the bottom vs local links
- npm run build (make sure to only do this after the env is updated)
- log in to ifast 

### for preview site
- go to cpanel for thehive-services
- then go to folder location below

### for live site
- go to whm
- list accounts
- click the orange cp icon for noveleshelf.com
- then go to folder location below

### folder location
- file manager
- public_html
- valorSites
- valor66
- empty assets folder 
- upload index, robots and sitemap to the valor66 folder from the created dist folder in repo
- upload contents of dist/assets into the assets folder
- always test it loaded
